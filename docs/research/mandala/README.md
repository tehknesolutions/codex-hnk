# HNK Mandala Research Workspace

Canonical research branch workspace for Mandala-first geometry.

Current gate: **V0.1A SOURCE CENSUS**.

The census intentionally starts empty because no repository-resident original Mandala asset has yet passed SOURCE_LOCK in this branch. Conversation screenshots and textual recollections are evidence pointers, not substitutes for original source bytes.

## Gate to advance

At least one high-quality Mandala source must be located with accessible original bytes, assigned `HNK-MANDALA-SRC-####`, hashed, dimensioned, provenance-recorded and marked `SOURCE_LOCKED`.

Only then begin geometric calibration and field census.

## Research invariants

- MANDALA-FIRST geometry.
- AK identity precedes raster identity.
- Pixel/IsoPixel/Voxel preserve AK provenance.
- OBSERVED / MEASURED / DERIVED / EXTERNAL_REFERENCE / HNK authority remain separate.
- `CHOIR-ID != COLOR-ID` unless explicitly superseded through governance.
- 441, 72 and 22 structures remain hypotheses/evidence targets until measured against locked source assets.
