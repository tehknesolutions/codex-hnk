# HNK 7×7 Maturity Profiler V1

O profiler compila os registros externos, internos, project/chat review e project-source gaps para cada uma das 49 células.

Nesta primeira versão somente dois eixos recebem valores derivados automaticamente:
- **Evidence Depth** — baseado no número de registros conceituais indexados.
- **Source Diversity** — baseado no número de famílias de proveniência.

**Formalization, Praxis, Governance e Cross-Link Density permanecem UNKNOWN** até auditoria dedicada. Isto implementa a regra `UNKNOWN_IS_NOT_ZERO` e impede que existência de software, prática ou texto seja promovida silenciosamente a maturidade.

O profiler não produz score composto e não ordena os 49 domínios.
