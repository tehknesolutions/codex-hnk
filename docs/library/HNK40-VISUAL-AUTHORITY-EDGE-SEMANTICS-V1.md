# HNK40 Visual Authority Edge Semantics V1

The Visual Canon V2 registry is a provenance source, not a semantic concept.

Accordingly, each G01-G40 visual-authority link uses `DERIVED_FROM` toward the `HNK40-VISUAL-CANON-V2` SOURCE node.

`REPRESENTS` remains reserved here for the approved compact semantic concepts (World, Role, Geometry, Sigil, Light, Shadow).

This correction changes edge typing only. It does not alter the Visual Canon V2 artifact, glyph forms, structural matrix, approved semantics, phonology, transliteration, PUA transport, or the HNK40/HENUVOKODAN boundary.
