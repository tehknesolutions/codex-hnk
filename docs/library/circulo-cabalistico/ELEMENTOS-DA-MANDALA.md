## Regra-mãe

Este arquivo é a fonte-mãe do inventário da Mandala. O objetivo é identificar e contar tudo antes de converter qualquer elemento em mecânica, classe, clã, guilda, ficha ou card.

`FONTE → ELEMENTO → OCORRÊNCIA → BLOCO → COR → SÍMBOLO → DIMENSÃO → RELAÇÃO → VISUAL → FICHA RPG → CARD HNK`

Não confundir:

- **ELEMENTO** = tipo conceitual único;
- **OCORRÊNCIA** = aparição visual de um elemento;
- **BLOCO** = célula/região delimitada da Mandala;
- **PIXEL** = unidade raster da imagem-fonte.

Contadores finais:

- `E_TOTAL` = elementos únicos;
- `O_TOTAL` = ocorrências visuais;
- `B_TOTAL` = blocos/sub-blocos delimitados.

Nenhum total é congelado antes do censo integral.

## 10. Cores

O censo cromático deve distinguir:

`FAMÍLIA CROMÁTICA → COR ESTRUTURAL → AMOSTRA RGB/HEX → OCORRÊNCIA → BLOCO`

Não contar como novas cores conceituais:

- antialiasing;
- artefatos JPEG/PNG;
- compressão;
- bordas interpoladas;
- pequenas variações rasterizadas da mesma área estrutural.

Catalogar separadamente cores de:

- fundo;
- setores;
- anéis;
- textos;
- letras;
- glifos;
- geometria;
- centro;
- Árvore;
- Rosa;
- bordas/separadores.

## 17. Estados epistemológicos internos

Mesmo sendo corpus canônico HNK/CABALA, cada dado conserva seu tipo:

- `CANON-SOURCE` — está efetivamente no livro/imagem canonizado;
- `CANON-ANALYSIS` — medição ou relação demonstrada sobre a fonte;
- `HNK-SYNTHESIS` — nova integração HNK aprovada por TW DA VINCI;
- `UNRESOLVED` — ainda não identificável com segurança.

## 18. Pipeline visual aprovado

Após o censo:

1. gerar **VISUAL-ID** para cada elemento;
2. criar representação isolada e legível;
3. criar vista técnica com medidas/posição;
4. criar vista simbólica/canônica;
5. criar ficha de RPG hermético HNK;
6. criar Card HNK.

O card não será um TCG baseado apenas em ATK/DEF. Será uma **ficha-card de RPG mágico/hermético**, usando estética premium de card games apenas como linguagem visual.

Famílias previstas de cards:

`SEFIRAH | ANJO/GÊNIO | CORO | PLANETA/ASTRO | SIGNO | ELEMENTO | LETRA HEBRAICA | GEOMETRIA | COR | CAMINHO | SÍMBOLO | RITUAL | CORRESPONDÊNCIA`

Campos de RPG só serão preenchidos quando derivados da fonte ou de uma `HNK-SYNTHESIS` aprovada.
