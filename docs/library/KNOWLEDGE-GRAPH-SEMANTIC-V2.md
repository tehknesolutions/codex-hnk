# HNK Knowledge Graph — Semantic Links V2

Primeiro lote de relações semânticas entre conceitos já documentados.

Foram escolhidas apenas relações suportadas pelas claims existentes. Similaridade temática, por si só, não gera equivalência ontológica.

Relações usadas neste lote:
- `USES`
- `INTEGRATES_WITH`
- `RELATED_TO`

O schema permite outras relações, mas `CORRESPONDS_TO` e `REPRESENTS` não foram forçadas quando a evidência não exigia esse vínculo.

Todos os links internos/projeto permanecem `HNK_CANDIDATE`; links diretamente derivados de uma mesma fonte externa podem permanecer `SOURCE_ASSERTED`.

V2 habilita a próxima densidade: contar relações semânticas reais além de DERIVED_FROM/INDEXED_IN.
