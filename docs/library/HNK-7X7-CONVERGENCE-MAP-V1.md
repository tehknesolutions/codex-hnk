# HNK 7×7 Convergence Map V1

Este mapa projeta as relações semânticas do Knowledge Graph V2 sobre a matriz HNK-7×7.

Fluxo:

`CONCEPT --semantic relation--> CONCEPT`
↓
`HNK_DOMAIN ↔ HNK_DOMAIN`
↓
`PILLAR ↔ PILLAR`

O mapa registra somente conexões que possuem uma aresta semântica materializada e conceitos já indexados em domínios.

Ausência de conexão no mapa significa **“ainda não há relação semântica materializada neste corpus”**, não que os domínios sejam incompatíveis ou desconectados em realidade.

A métrica não representa verdade, importância, eficácia ou aprovação canônica.
