# HNK-7×7 Canon Reconciliation

O registry foi reconciliado com a Issue #173.

## Invariante

Os 49 `domain_id` permanecem estáveis (`P01-L01 … P07-L07`), mas nomes e definições não são mais combinações genéricas geradas por Pilar × Nível. Cada célula usa o nome e a definição aprovados no contrato conceitual da Issue #173.

O validator dedicado bloqueia:
- número diferente de 49 células;
- IDs duplicados ou ausentes;
- perda do lock para Issue #173;
- retorno acidental aos nomes genéricos “Nível — Pilar”.

Esta mudança não aprova automaticamente relações da Biblioteca, HNK-40, Sephirot, Paths, Days ou HENUVOKODAN.
