# HNK Glyph Registry Gap V1

The Living Grimoire search contract currently exposes glyph coverage as `NOT_INDEXED`.

This is intentional. A repository audit across `tehknesolutions/codex-hnk`, `Tehkne-Solutions/hnk-codex-365`, and `Tehkne-Solutions/codex-hnk-app` did not locate a canonical machine-readable registry for the expected HNK 40 glyph set using the terms HENUVOKODAN, glyph, glifos, and G01.

## Governance

This gap record does not define glyph identities and does not create placeholders.

HENUVOKODAN must not be treated as synonymous with the HNK glyph registry. The next legitimate gate is to locate or ingest the creator-approved source for the HNK 40 glyphs, preserving exact IDs, names, visual assets, provenance, and approved equivalences.

`0 materialized glyphs != 0 canonical glyphs`.
