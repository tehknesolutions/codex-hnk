# HNK Binah — Portal 109 Safety Disposition V1

**Status:** `SAFETY SUBGATE APPROVED / CANONICAL REFERENCES STILL BLOCKED`  
**Scope:** Day 109 · Portal Binah / end of Atziluth  
**Tracking:** Issue #17

## Decision

The Chapter 3 source includes a paper-burning closure. The reviewed Day 109 draft already freezes two governing rules:

1. burning paper is optional and only occurs when safe;
2. production must provide a no-fire closure with equivalent completion semantics, and XP may never require fire.

This record approves the production no-fire disposition. It does **not** approve the unresolved Sintonizador, Saturn→Jupiter transition or visual/sigil references.

## Canonical source path vs product adaptation

### Textual/source path — optional

A fire-based paper closure may only exist as an optional path where local context, supervision, materials and environment make it safe and lawful. It must never be the only way to finish the Portal.

### Product default — no-fire closure

The HNK product may present the following explicit adaptation as the default safe closure:

```text
1. finish the written synthesis;
2. read only the portion the user chooses to review;
3. mark the paper as ENCERRADO / CONCLUÍDO;
4. tear it by hand into several pieces OR fold it closed;
5. place the pieces/folded paper in an opaque envelope, disposal container or recycling path appropriate to the user's privacy needs;
6. confirm Return Gate and completion state.
```

No flame, lighter, candle, heat source, blade or special tool is required.

For accessibility or privacy, a user who should not tear/discard the paper may simply fold it, mark it closed, place it in an envelope/container and complete the same product-level closure state.

## Semantics

The no-fire path is an **HNK product safety adaptation**, not a claim that the source text originally prescribed tearing/folding instead of burning.

Both supported paths share the same product completion semantics:

- intentional closure of the written phase;
- private material remains under user control;
- Return Gate is completed;
- no additional XP is granted for fire, destruction intensity or irreversible disposal;
- the server receives only structural evidence, never a requirement to prove that paper physically burned.

## Fire-path guardrails

If a fire option is ever exposed in product documentation or guided mode:

- it is optional;
- local law/building rules and environment govern;
- never indoors where flame is prohibited or unsafe;
- never near flammables, children, animals or an obstructed exit;
- never unattended;
- no accelerant;
- no XP, badge, completion advantage or spiritual rank for choosing fire;
- Safety Stop immediately exits to the no-fire path.

The product should prefer the no-fire closure unless a separate release review explicitly enables a fire path for a supported context.
