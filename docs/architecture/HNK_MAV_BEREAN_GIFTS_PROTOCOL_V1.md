# HNK-MAV Berean Gifts Protocol V1

Status: PROPOSED SPECIALIZATION
Upstream: HNK_EXPERIMENT_PROTOCOL_V1, HNK_EVIDENCE_LEDGER_V1, HNK_CLAIM_DOSSIER_EVIDENCE_REVIEW_GATE_V1

## Purpose

Provide a prospective, auditable profile for reports involving prophetic/informational perception, healing/intervention and external events without creating a competing evidence system.

## Core sequence

PERCEPTION_OR_PRAYER
→ PRIOR_RECORD
→ LOCK
→ PREDECLARED_CONFIRMATION_CRITERION
→ EVENT
→ EVIDENCE
→ ADVERSARIAL_REVIEW
→ CLASSIFICATION

## Tracks

- PROPHETIC_INFORMATIONAL
- HEALING_INTERVENTION
- EXTERNAL_EVENT
- OTHER

## Observability levels

- S1 SUBJECTIVE — internal experience/report.
- S2 INTERSUBJECTIVE — independent human corroboration/correlation.
- S3 EXTERNAL — externally observable or measurable evidence.

These levels classify observability/evidence, not supernatural certainty.

## Result states

CONFIRMED, PARTIAL, AMBIGUOUS, NOT_CONFIRMED, INCONCLUSIVE.

## Rules

1. Failures are data and remain in the dataset.
2. Prediction precedes interpretation; the original record is locked.
3. Testimony is preserved; causality is not presumed.
4. Absence of an ordinary explanation does not automatically establish supernatural causation.
5. Possibility of coincidence does not by itself demonstrate coincidence.
6. All attempts within the declared collection window count.
7. Post-event reinterpretation cannot rewrite the preregistered record.

## Minimum preregistration fields

case_id, track, timestamp/timezone, raw perception/prayer/intention, target descriptor, expected outcome, time window, success/failure/ambiguity criteria, known prior information, and available pre-event witnesses.

## Post-event fields

observed outcome, timestamp, evidence references, witnesses, alternative explanations, possible information leakage, relevant base-rate/chance considerations, result classification, and a separate interpretation field.

## Healing safety boundary

This protocol is research/evidence governance. It does not diagnose disease and must not delay, replace or discourage appropriate medical evaluation or treatment.

## External-event profile

Where feasible, predeclare spatial and temporal windows and use independent public measurements or records.

## Informational/vision profile

Prefer immutable timestamped records made before the event. Compare the original wording literally against the later event and retain misses, partial matches and ambiguous cases.

## Integration

A Berean Gifts case should reuse the existing experiment preregistration lock, evidence ledger, claim dossier and human review gates. No result automatically proves causality, supernatural efficacy or HNK canon.
