TEHKNE-OS -> technological evidence/know-how -> CODEX-HNK / TECNOLOGIA
CODEX-HNK -> canonical contracts -> HNK-KODE / HNK-VERSE
HNK-KODE -> linguistic/computational contracts -> HNK consumers

Flow can be bidirectional; authority is not symmetric.
