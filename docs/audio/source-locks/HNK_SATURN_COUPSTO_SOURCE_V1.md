# HNK Saturn Planetary Tone Source Lock V1

Status: **SOURCE LOCK / EXTERNAL REFERENCE ADOPTED FOR HNK PRODUCT MAPPING**

Scope: Binah · Day 107 · Saturn audio definition; reusable input for Portal 109 Saturn→Jupiter transition review.

## 1. Why this source lock exists

The Binah source plan names a `frequência planetária de Saturno`, but it does not provide a numeric Hz value. The project therefore cannot derive a number from the ritual label alone.

This document records an explicit **new HNK editorial source adoption** rather than pretending the number was present in the original plan.

## 2. Adopted planetary-frequency system

HNK adopts Hans Cousto's **Cosmic Octave** mapping as the normative numeric source for the planetary-tone layer where the Codex explicitly requests a planetary frequency and the source plan omits the number.

Normative references:

- Hans Cousto / Planetware, *The Cosmic Octave Tuning Forks*;
- Planetware tuning data: `https://www.planetware.de/download/tuning_data_planets.pdf`;
- supporting publication copy: `https://www.planetware.de/download/cousto/LesTons.pdf`.

The system derives audible tones by octave-transposing astronomical periods. It is used here as a reproducible symbolic/acoustic mapping, not as evidence that a planet emits an audible sound in space or that listening produces a neurological, medical or spiritual effect.

## 3. Frozen planetary tones relevant to current scope

```text
Saturn  = 147.85 Hz
Jupiter = 183.58 Hz
```

Day 107 uses Saturn only.

The Jupiter value is recorded here because Portal 109 explicitly names a Saturn→Jupiter transition. This source lock does **not** by itself define how that transition is sequenced or layered; Portal 109 still requires its own transition freeze.

## 4. Separation from binaural difference

The Cosmic Octave source supplies the planetary **carrier/tone identity** only.

It does not supply the binaural beat difference used by the HNK application.

The HNK app architecture independently defines a canonical example of Theta synthesis as:

```text
base carrier = 432 Hz
right = base + 4 Hz
Theta difference = 4 Hz
```

For Day 107, the product therefore uses:

- Cousto source for Saturn carrier identity: `147.85 Hz`;
- HNK app source for the binaural difference: `4 Hz`;
- arithmetic right carrier: `151.85 Hz`.

This is an explicit two-source reconciliation. `4 Hz` is **not** claimed to be a Saturn frequency.

## 5. Epistemic boundary

UI and documentation may state that the preset reproduces an HNK Saturn planetary-tone mapping and a 4 Hz binaural difference.

They may not state that playback:

- measures or guarantees Theta brain activity;
- transmits a physical force from Saturn;
- treats disease;
- proves a spiritual state;
- guarantees concentration, initiation or occult effects.

## 6. Approval boundary

This source lock supplies provenance for a dedicated Day 107 audio freeze. It does not publish a runtime preset by itself.
